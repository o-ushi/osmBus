## 概要（説明・4,000文字以内）

```
osmBus は、行き先を決めて、乗れるバスを選ぶアプリです。バス停で来たバスの番号を入れると、乗っていいバスかどうかをすぐに答えます。乗ったあとは、降りるバス停が近づくとアラームで知らせます。

路線と停留所は OpenStreetMap のデータを端末に保存して使うので、バスの判定と番号表は通信がなくても動きます。

■ 目的地を決める
・地名を検索するか、地図を長押しして目的地を決めます
・よく行く場所の登録と、目的地の履歴から選べます
・出発地は現在地のほか、地図で選んだ場所にもできます

■ 乗れるバスがわかる
・目的地を決めると、今いる場所から乗れるバスの番号表が出ます。乗り換えが要る経路も並びます
・テンキーで番号を入れると「乗ってよい」か「見送る」かを判定。進む方角、降りるバス停、着くまでのおよその時間も出ます
・表に無い番号は「この区間に無い番号」から伝えられます

■ 乗ってから
・バス番号を長押しで乗車、もう一度長押しで降車
・降りるバス停までの距離を、色つきのバッジで表示します
・降車バス停に近づくと、遠い順にアラームが 1〜3 回鳴ります。距離・サウンド・音量・バイブ・通知は設定で変えられます
・画面を消していても、アプリが裏にあっても、通知とアラームで知らせます
・逆方向のバスに乗ってしまったようなときも知らせます
・乗り換えのある経路では、乗換地点で降りて次のバスへ

■ 路線図
・バス番号で路線を探し、停留所と経路を地図で見られます
・路線図から直接、乗車・降車もできます

■ 路線データ
・周辺のバス路線を OpenStreetMap からダウンロードし、端末に保存します（使う前に同意をおたずねします）
・停留所の順番や位置がおかしい路線は、その場で確かめて直せます

■ Apple Watch
・乗っているバスの番号、降りるバス停までの距離、次に乗り換えるバスの番号を手首に表示します
・番号を長押しで乗車・降車・乗り換え。iPhone を取り出さずに操作できます
・降車バス停が近づくと、iPhone のアラームと同じ回数だけ手首を震わせます（Apple Watch のアプリを表示しているとき）
・文字盤に置いたボタンから、osmBus をすぐ開けます

■ 地図
・OpenStreetMap の地図で表示します
・ご自身の Google Maps API キーを設定すると、Google マップでも表示できます

■ 同期とバックアップ（任意）
・iCloud で、路線データ・登録した場所・目的地の履歴・直した停留所・設定を同じ Apple ID の iPhone 間で同期
・書き出しと読み込み

■ 3言語対応
日本語・English・Tiếng Việt

■ プライバシー
・ユーザー登録不要。広告・アクセス解析・トラッキングなし
・目的地・履歴・登録した場所は端末内に保存し、開発者のサーバーへは送りません
・バスの判定と番号表は端末の中だけで計算します
・路線データの取得、地名検索、地図の表示のときだけ、必要な範囲で外部のサービスと通信します。送り先と内容はアプリ内の「プライバシーとデータ」で確かめられます
・「すべてのデータを削除」で、目的地・履歴・登録した場所・同意・路線データを消せます

■ 対応端末
・iPhone（縦画面のみ）
・Apple Watch（watchOS 10 以降。iPhone のアプリといっしょに使います）

路線と停留所のデータは © OpenStreetMap contributors です。地域によっては、路線が登録されていなかったり、古かったりすることがあります。
```

## 審査員へのメモ（App Review Information > Notes）

```
2026/11/14
いつもアプリを審査頂きましてありがとうございます。
先に公開したVersion 2.0.4に対して、下記修正を行なっています。
・Apple Watch アプリ（watchOS 10 以降、iPhone アプリに同梱、単体では動作しません）と文字盤用のコンプリケーション（WidgetKit）を追加
・Apple Watch は iPhone アプリの乗車状態を表示するだけで、経路の計算・位置情報の取得・外部との通信は行いません。表示するのは、乗っているバスの番号、降りるバス停までの距離、次に乗り換えるバスの番号です
・Apple Watch でバス番号を長押しすると、iPhone アプリの番号の長押しと同じく、乗車・降車・乗り換えを行います
・降車バス停が近づいたときの手首の振動は、Apple Watch のアプリが前面にあるときだけ鳴ります。ワークアウトセッションやバックグラウンドの実行時間の延長は使っていません
・コンプリケーションは osmBus を開くためのボタンのみで、データは表示しません
・iPhone と Apple Watch の間のやりとりは Apple の Watch Connectivity のみを使い、開発者のサーバーや第三者への送信はありません
・新たな権限の要求はありません
先に一度承認をいただいた内容から、上記修正以外の機能変更やビジネスモデルの変更はございません。
お手数をおかけして恐縮ですが、ご確認のほどよろしくお願いいたします。
```
