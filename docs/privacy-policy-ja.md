# osmBus プライバシーポリシー

最終更新日: 2026年11月1日

osmBus（以下「本アプリ」）は、バスに乗るかどうかの確認、番号表、路線図、地図、場所の検索、到着の通知を提供します。料金の支払いやアカウント登録はありません。

本ポリシーは、本アプリが扱う情報、端末の外へ送る相手、保存のしかた、削除のしかたを説明します。

## 1. 端末の中だけで扱う情報

バス番号の判定、番号表、乗換、乗車中の距離、到着の目安は、端末に保存した路線データで計算します。入力したバス番号は、端末の外へ送りません。

この計算のために端末へ保存するものは、次のとおりです。

- 現在地、地図で指定した出発地、目的地とその履歴、登録した場所
- ダウンロードした路線、停留所、路線の形、その保管用の複製、ユーザーが直した停留所
- 表示、通知、テンキー、言語などの設定
- 路線データの取得に同意したかどうか
- 不具合を調べるためのログ（位置は約100mの単位に丸めて記録します）

## 2. 端末の外へ送る情報

広告のための追跡や、データの販売は行いません。送信は、次の機能を動かすときに限ります。

### 路線データの取得（同意したときだけ）

設定で OpenStreetMap データの利用に同意したときだけ、Overpass API へ現在地の座標、検索半径（約80km）、取得する路線の ID を送ります。目的は、周辺のバス路線と停留所を取得して端末に保存することです。

送り先は、順に overpass-api.de、Kumi Systems（overpass.kumi.systems）、Mail.ru（maps.mail.ru）です。つながらないときは次の運営者で再試行します。同意をオフにするか撤回すると、この送信は止まり、保存した路線の正本は使えなくなります。撤回したときは正本を削除します。

各運営者がアクセス記録をどれだけ残すかは、各運営者の方針によります。

### 地名の検索

行き先や出発地を名前で探すとき、入力した語句を送ります。

- Nominatim（nominatim.openstreetmap.org）: 検索語句と、結果の言語を決めるための言語コード
- Photon（photon.komoot.io）: Nominatim が使えないときの予備です。検索語句に加え、近くの候補を優先するための現在地付近または地図中心の座標
- Apple の地図検索（iOS で、検索語句に日本語が含まれるとき）: 検索語句。日本語の呼び方で場所を探すため。近くを優先するときは、現在地付近または地図中心の座標も送ります

バス番号の検索は、端末内の路線データだけで行います。

### 地図の表示

地図を開くと、見えている範囲のタイルを取得します。この範囲から、見ている場所が分かります。

- 通常は OpenStreetMap（tile.openstreetmap.org）。取得できないときは OSM France（tile.openstreetmap.fr）

### Google マップを使うとき

API キーがあり、設定で Google マップがオンのときは、地図の表示に Google マップ SDK を使います。キーは起動時に SDK へ渡します。地図を表示すると、見えている範囲が Google に送られます。

同じ SDK は、Google のプライバシー申告に従い、次の情報を解析と地図機能のために Google へ送ることがあります。

- クラッシュに関する情報
- 端末の識別子
- その他の情報
- 性能に関する情報
- 地図の操作に関する情報

本アプリは、これらを広告の追跡には使いません。Google による処理には、Google のプライバシーポリシー（https://policies.google.com/privacy）が適用されます。

ユーザーが iOS の設定画面で入力した API キーは、この端末のキーチェーンに保存します。ビルド時に組み込んだキーは、アプリの一部として入ります。

## 3. 保存場所と期間

- この端末: 第1節の情報。路線データはアプリの保存領域、その他の多くはアプリの設定領域に保存します。API キーはキーチェーンです。
- iCloud: 設定で iCloud 同期をオンにしたときだけ、路線データ、登録した場所、目的地の履歴、直した停留所、番号表・到着アラート・テンキー・言語の設定を、そのユーザー自身の iCloud Drive に保存します。開発者がこの内容を受け取ることはありません。地図の API キーと開発用のログは同期しません。
- バックアップ: ユーザーが書き出したファイルには、路線データ、登録した場所、目的地の履歴、直した停留所、番号表・到着アラート・テンキー・言語の設定が入ります。ファイルの送り先は、ユーザーが選んだ相手です。

保存した情報は、ユーザーが消すか、アプリの保存領域を消すまで残ります。キーチェーンの項目は、アプリを削除したあとも端末に残ることがあります。API キーを消すには、設定の地図でキーを空にして保存してください。

## 4. 削除

「設定」の「プライバシーとデータ」にある「すべてのデータを削除」は、次を消します。

- 目的地、目的地の履歴、登録した場所、直した停留所
- 路線データの取得への同意と、路線データの正本

一般設定、路線の保管用の複製、Google マップの API キー、ログは消えません。保管用の複製は、設定の保管庫から扱えます。

すでに Overpass、地図の提供元、Nominatim、Photon、Apple、Google が受け取った情報は、本アプリからは消せません。各提供者の手続きによります。

## 5. 位置情報

現在地は、番号表、路線データの取得、近い地名の優先、乗車中の距離と到着通知に使います。許可は iOS の設定で変更できます。

アプリを閉じているあいだの位置情報は、乗車中に到着を知らせるときだけ使います。降車すると止まります。

## 6. ログ

ログは端末内に残し、自動では送りません。開発者向けの画面から、ユーザーが自分でメールなどに添付したときだけ、端末の外へ出ます。

## 7. 子どものプライバシー

本アプリは、子どもを対象とした広告や、広告目的の情報収集を行いません。

## 8. 改定

送る相手や送る項目が変わるときは、本ポリシーを更新します。路線データの取得に新しい同意が必要になったときは、アプリ内で取り直します。
