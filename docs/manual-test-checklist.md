- [ ] 新規状態で初回同意画面が閉じられず、3事業者・送信項目・目的が3言語で読める
- [ ] 「同意しない」後、Google Routes、Google Maps、Google Geocoding、Apple MapKit検索/ジオコード、3つのOverpassホストへ通信しない
- [ ] 拒否時に保存済み目的地・登録地を閲覧でき、対象機能には同意が必要な表示が出る

- [ ] 設定とヘルプの両方から「プライバシーとデータ」を常時開ける
