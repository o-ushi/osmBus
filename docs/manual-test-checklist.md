# 手動テストチェックリスト

## 同意と通信

- [ ] 新規状態で初回同意画面が閉じられず、3事業者・送信項目・目的が3言語で読める
- [ ] 「同意しない」後、Google Routes、Google Maps、Google Geocoding、Apple MapKit検索/ジオコード、3つのOverpassホストへ通信しない
- [ ] 拒否時に保存済み目的地・登録地を閲覧でき、対象機能には同意が必要な表示が出る
- [ ] 同意後に場所検索、地図、経路検索、バス番号判定、Overpass路線図が動作する
- [ ] 設定とヘルプの両方から「プライバシーとデータ」を常時開ける
- [ ] 同意撤回直後から新規通信が停止し、再同意後に再開する
- [ ] 同意版を上げたテストビルドで再同意画面が表示される

## 保存と削除

- [ ] 旧UserDefaultsにAPIキーがある状態から起動し、Keychainへ移行後に旧値が削除される
- [ ] APIキー保存・再起動・削除が正常に動作する
- [ ] 「すべてのデータを削除」で目的地、履歴、登録地、APIキー、同意が削除される
- [ ] 全データ削除後、同意画面が再表示される
- [ ] 購入履歴と一般設定が削除対象外であることを確認する

## UI・端末

- [ ] 日本語・英語・ベトナム語で文言欠け、切れ、重複NavigationStackの不自然な戻る動作がない
- [ ] iPhone実機/シミュレータで縦向きに固定される
- [ ] iPad向けインストール対象として表示されない
- [ ] 位置情報を拒否/許可/常時許可した各状態でクラッシュしない

## 審査提出

- [ ] 署名なしDebugビルドが成功する
- [ ] Release ArchiveのPrivacy Reportを確認する
- [ ] 公開プライバシーポリシーURLと問い合わせ先を差し替える
- [ ] App Privacy回答、審査ノート、アプリ内表示が一致する
