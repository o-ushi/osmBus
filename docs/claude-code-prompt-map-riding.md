## ステップ 1. すべての地図に「現在地に戻る」ボタン

`BusMap` に右下のボタンを1つ足し、3つの画面全部に出してください。画面ごとに別実装を作らないでください。

- 押したら、カメラを現在地へアニメーションで寄せる。ズームは 15。現在地が無いときだけ、その地図の `initialCenter` へ寄せる。
- 押しっぱなしの追従はしない。1回押すとそこへ動くだけ（Swift の `shouldFollowUser: false` と同じ）。
- 見た目は Swift の `MapLocationButton` に合わせる。直径 44、白丸、軽い影、北向きの位置アイコン、色は `Color.fromRGBO(66, 133, 244, 1)`。
- 右下の OSM クレジットと Google のロゴに重ならないよう、既存の `overlayInsets` の下側を足して配置する。
- アクセシビリティの読みは「現在地に移動」。
- `BusMap` に現在地の `GeoPoint?` を渡せるようにする。路線図と経路地図と行き先シートは、それぞれ持っている GPS（`TripController` の現在地。手動の出発地ではない）を渡す。

## ステップ 2. 地図の左上に、ホームと同じ距離バッジ

ホームの `_DistanceBadge` を、地図からも使う1つのウィジェットに出してください。大きさ、色、角丸、文字の大きさをホームと別定義にしないでください。

ホームと同じ条件で出します。

- 未乗車で目的地があるときは、目的地までの直線距離。
- 乗車中は、今の降車停留所までの直線距離。測る起点は GPS（手動の出発地では測らない）。
- 路線図から、目的地なしで乗っているときは「—」。
- 距離も乗車も無いときは出さない。

色は今の `DistanceColorBand` のままです。3km 以上は青、1km 以上は緑、500m 以上は黄、200m 以上は橙、200m 未満は赤。文字は青・緑・赤が白、黄・橙が黒。

置き場所は各地図の左上（アプリバーの下、セーフエリアの内側）です。ホームのアプリバーには今まで通り置きます。

削除するもの:

- 路線図の下の情報カードにある「あと ○○」の文字（`bus_route_browser_screen.dart` の `_routeInfo`）。カードの系統名・方向・乗車中の表示・停留所数は残す。
- 地図のほかの場所に距離の数値が出ていたら、それも消す。左上のバッジだけにする。

バッジの操作はホームと同じです。乗車中のタップで経路地図を開く。すでに経路地図なら閉じる。長押しはナビ中止の確認です。

## ステップ 3. 乗車中の路線を、経路地図でもオレンジにする

路線図はすでに、乗車中の線が `Colors.orange`、未乗車が `AppTheme.accent` です。経路地図（`route_map_screen.dart`）は乗車中も `colorScheme.primary`（青）のままなので、そこを直します。

- 今乗っているレグの線はオレンジ。
- まだ乗っていないレグ、降りたあとのレグは、今の灰色（`Color(0xFFB0BEC5)`）のまま。
- 未乗車で経路を見ているときは、今まで通り青。
- 徒歩の点線は灰色のまま。
- 現在地の丸は青のまま（ステップ 6）。乗車中に丸までオレンジにしない。

## ステップ 4. 裏に回っても、画面がオフでも、乗車を続ける

症状: 乗車中にアプリを裏へ出す、または画面をオフにすると、降車したことになり、到着アラームも鳴らない。Swift は乗車のまま、画面オフでも降車停留所までの距離でアラームが鳴る。

いまのコードでは `onPaused` は降車していません。乗車（`_riding`）はメモリだけです。裏でプロセスが止まると、戻り先では乗っていない状態になります。測位も止まるので `_checkRiding` が走らず、アラームも鳴りません。

Swift に合わせて、次を全部やってください。

1. 乗車開始で裏の測位を始めるとき、iOS の許可が「使用中のみ」なら「常に許可」を求める。Swift の `requestAlwaysAuthorization()` と同じタイミングです。すでに常に許可なら何もしない。
2. Android は、使っている `geolocator` の版が求めるフォアグラウンドサービスの宣言と、画面オフの測位に必要な権限をマニフェストへ足す。クラス名はプラグインのドキュメントか、プラグイン同梱のマニフェストから取り、憶測で書かない。
3. 位置ストリームがエラーで終わる、または完了しても、乗車中ならストリームを張り直す。そこで `endRiding` を呼ばない。
4. `AppLifecycleState` の `inactive` / `hidden` / `paused` / `detached` では降車しない。前面に戻ったとき、乗車中なら測位が続いていることを確認し、止まっていれば張り直す。
5. プロセスが殺されても、次に開いたときに同じ乗車を復元する。復元するのは系統、レグ、降車停留所、乗った時刻、経路地図発か路線図発か、目的地です。ユーザーが降車するかナビを中止するまで消さない。復元したあとも裏の測位を再開する。
6. アラームの音は、前面でなくても `_checkRiding` から鳴らす（今そうなっているので、前面のときだけ鳴らす変更は入れない）。裏では通知も今まで通り出す。

画面オフのあいだ鳴らせるのは、プロセスが生きているときだけです。1 と 2 でプロセスを生かし、5 は殺されたあとに「降車したように見える」のを防ぎます。

## ステップ 5. 目的地そのものをゴールにする

例: ハノイのオペラハウスを行き先にすると、ゴールが建物を通り過ぎた位置になったり、ずっと手前になったりする。

原因は、地図のゴールが目的地の座標ではなく、半径 550m 以内で直線距離が一番近い停留所になっていることです（`local_planner.dart` の `bestAlightAfter`）。経路が建物の横を通っていても、別の停留所の方が直線で近いと、そこが降車になり、赤いゴールもそこへ付きます。

直したあとのルール:

- ゴールの印は、検索や長押しで保存した目的地の座標そのもの。停留所に吸い寄せない。保存されている座標がすでに目的地と違う場合だけ、検索結果の座標を目的地として保存しているかを確認して直す。座標が正しいのに表示だけ停留所なら、表示を直す。
- 降車停留所は「目的地をその路線のポリラインへ下ろした点」の直前の停留所と直後の停留所のうち、目的地までの徒歩が短い方。同距離なら、進行方向で先に着く方（手前）にする。何停留所も手前、または最接近点を通り過ぎた先は選ばない。
- 選んだ停留所から目的地までの徒歩が `alightRadiusMeters`（550）を超える路線は、今まで通り直通の降車なしとする。遠くを通るだけの路線を候補に残さない。
- 乗車中の「あと」の距離は、今まで通り降車停留所まで。ゴールの印の位置とは別です。
- 経路地図では、最後の降車停留所から目的地までを、乗換の徒歩と同じ灰色の点線で結ぶ。降車停留所と目的地が同じ点なら点線は要らない。

`flutter/test/local_planner_test.dart` に、次の2つを足してください。

- 経路が目的地の横を通る。直線距離だけ見ると、ずっと手前の停留所の方が近い。降車はその最接近点の隣の停留所になる。
- 直線距離だけ見ると、目的地を通り越した先の停留所の方が近い。降車は最接近点の隣になり、通り越した先にはならない。

既存の「両端の 100m なら端の停留所で降りる」テストは、新しいルールでも成り立つので通したままにしてください。

## ステップ 6. 経路の地図に、出発地・ゴール・路線・現在地・停留所を出す

路線図に揃えます。対象は経路地図と路線図です。行き先シートは地点を選ぶ地図なので、現在地ボタン（ステップ 1）と、乗車中か目的地があるときの距離バッジ（ステップ 2）だけで、路線や停留所は足しません。

経路地図に出すもの:

- 出発地。手動で選んだ出発地があるとき、その点。GPS だけが出発地のときは、下の現在地の丸と重ねない。
- ゴール。ステップ 5 の目的地の座標。赤い降車の印は降車停留所のまま残し、ゴールと別の印にする。
- 路線。ステップ 3 の色。乗車中のレグはオレンジ、乗っていないレグは灰色、未乗車の閲覧は青。
- 現在地。ブランド青（`AppTheme.brandBlue`）の丸に白い縁。直径は Swift の 26 に揃える。GPS が更新されるたびに、直前の位置から次の位置へ短く補間して滑るように動かす。飛び移りにしない。OSM と Google の両方。
- 停留所。各レグの乗車停留所から降車停留所まで。停留所列はカタログの路線を `relationId` で引き、`boardIndex` から `alightIndex` までを使う。`ItineraryLeg` は端の停留所しか持っていない。
- 乗換で歩く区間の点線と、乗換の印は今のまま。

路線図に出すもの:

- 今ある停留所と、乗車中のオレンジの線はそのまま。
- GPS の位置は、出発地のピンではなく、上と同じ動く青丸にする。手動の出発地があるときだけ、出発地のピンを別に出す。
- 目的地があるときは、同じゴールの印を出す。

現在地の丸は線や停留所より手前に描いてください。
