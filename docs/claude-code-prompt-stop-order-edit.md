## ステップ 1. 道路の上で明らかに戻っている路線は、端末が読み込み時に並べ替える

`StopOrderRepair.repair` を変える。

- 停留所の一つが、線から 120m 以内の場所に 500m 以上離れて二度落ちても、路線全体を直さずに戻らない。
- 各停留所は、線に一番近い位置（今の `along`）で並べる。二度落ちた停留所も、一番近い方の位置を使う。
- 線から 120m より遠い停留所は、今まで通り元の位置のまま残す。
- 線から 120m 以内の停留所をメンバー順に見て、前より線上で 1km 以上戻っているものが無い路線は、今まで通り並べ替えない。

これは路線データを読み込んだときに端末が行う。アプリの更新や、ユーザーの操作は要らない。

E05 の復路（Smart City → Long Biên、relation 13534192）では、メンバー順の末尾近くにある「Siêu thị điện máy PiCo - 173 Xuân Thủy」が、「Tòa nhà Indochina Tower - Đối diện ĐHQG Hà Nội」と「79 Xuân Thủy」の間に入る。テストはこの形を、線と停留所の座標を縮めたフィクスチャで再現する。Indochina Tower に相当する停留所は、線の近くに離れて二度落ちる。その場合でも PiCo が間に入ること。

## ステップ 2. それ以外の路線は、ユーザーが路線図で自分で並べ替える

自動の並べ替えで直らない路線や、自動の並びが違う路線を、その人が端末の中で直せるようにする。他の端末には送らない。アプリの更新は要らない。

入口は次の両方。

- 経路地図: 乗車中の行の `AlightStepper` の直下。
- 路線図: 開いている路線に、乗車中でなくても出す。乗車中でステッパーがあるときは、その直下。

表示:

- まだ手直ししていない: 「停留所順を直す」。タップでシートを開く。
- この路線を自分で直した順を使っている: 「自分で直した順を使っています」。タップでシートを開く。

シート:

- その方向の停留所を、今の表示順で全部出す。
- ドラッグで順番を入れ替えられる。
- まだ手直ししていないときのボタンは「この順で使う」。押すとシートを閉じ、その `relationId` の停留所 ID の順を、今の公式順の適用と同じ `stopOrder.applied` に書く。番号表、経路地図、路線図、− ＋ は、その順の `stops` を見る。
- すでに手直ししているときのボタンは「元に戻す」。押すとその路線の記憶を消し、ステップ 1 を通したあとの並びに戻る。
- 順番を動かしていないときは「この順で使う」を押せない。

覚えた ID が、今の路線の停留所に 1 つでも無くなっていたら、今の `_withOfficialOrder` と同じく、その路線の記憶を捨てる。路線データを更新して停留所が増減した場合がこれです。

テスト:

- ドラッグで入れ替えた ID の順を保存すると、その路線の `stops` がその順になる。別の路線は変わらない。
- 「元に戻す」でその路線の記憶が消え、ステップ 1 の並びに戻る。
- 覚えた ID の一つが路線から消えたら、その記憶は無くなり、ステップ 1 の順に戻る。
