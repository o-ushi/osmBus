# Claude Code への指示

次の文面を、そのまま作業員への最初のメッセージにする。

---

`docs/spec_migration.md` に沿って、必要なモデル、サービス、および UI をすべて一気に実装してください。

仕様書が実装の唯一の仕様です。仕様に無い画面や Swift の機能を先回りして移植しないでください。仕様と矛盾する実装は、仕様の方に合わせてください。

制約:

- 新規コードは `flutter/` 以下だけ。既存の Swift、Xcode プロジェクト、`osmBus/` は読んでも変更しない。
- 乗車可否と番号表はローカルの路線 JSON だけで計算する。Google の API は呼ばない。
- iCloud は iOS の Documents コンテナへ同じ JSON を置く。CloudKit レコードにはしない。Android では同期を無効にし、バックアップの書き出しと読み込みだけにする。iCloud が使えないときもアプリは起動する。
- 単体テストは仕様書 §12 の 7 項目を満たす。完了前に `flutter test` と `flutter analyze` を実行し、失敗を残さない。
- パッケージの版が解決できなければ、同じ役割の現行安定版へ替え、`flutter/IMPLEMENTATION.md` に理由を 1 行書く。
- コミットはしない。

完了報告は短くしてください。作ったディレクトリ、テスト結果、iOS で人間が Developer ポータルに作るべき iCloud コンテナ ID、仕様からずらした点があればその点だけ。
